# Práctica 2.3: Formulario Template Driven

Formulario de registro básico en Angular usando `FormsModule`, `ngForm` y `ngModel`.

## Ejecutar

```bash
npm install
npm start
```

La aplicación permite capturar nombre completo, correo, teléfono, edad y contraseñas. Al registrar los datos, muestra debajo del formulario el mensaje `Registro completado` y un resumen de la información capturada.
